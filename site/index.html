What it does

It watches, never steers.

01 — PRINCIPLE

It only ever watches

Observe-only by design. There is no control channel and never will be. vigie reads state from Claude Code's registry and transcripts — it can't start, stop, or steer a session, so it can never get in your way.

02 — REACH

Many machines, one watch

Point each machine's watcher at your server and every machine lands on one board. Presence and status come from Claude Code itself, so a session shows up the moment it starts — no per-session setup.

03 — SURFACES

Two ways to keep watch

A Bubble Tea TUI in your terminal, and a read-only web dashboard the daemon serves over HTTP — a browser mirror of the TUI. Same truth, wherever you're looking.

04 — ATTENTION

Alerts that find you

When a session starts waiting, stalls on a hung tool, or errors, vigie tells you: a desktop notification and a next-waiting hotkey that jumps you straight to whatever needs a human.

The status key

Seven states, read at a glance.

Every session sits in exactly one state. Three of them mean a human is needed — those are the ones vigie surfaces and notifies on.

workingrunning a tool or writing a reply
thinkingreasoning inside a turn
waitingpaused on a permission promptattention
stalleda turn parked on a tool that never returnedattention
idlealive but quiet, awaiting your prompt
errorthe last turn hit an API errorattention
endedthe session's process is gone

Install

Watching in four commands.

Grab the Linux release, point a machine at your server, and start streaming its sessions. The daemon (vigied) runs wherever you host; each machine runs the vigie client.

  1. Download the release

    Pull the latest vigie client archive for Linux from GitHub Releases.

  2. Point it at your server

    vigie init writes the client config and installs the reporting hooks into Claude Code.

  3. Start the watcher

    Run vigie watch — or enable the systemd unit — to stream this machine's sessions.

  4. Open the board

    Watch from your terminal with vigie tui, or open the web dashboard your daemon serves.

install · linux/amd64
# 1 · install the client into ~/.local/bin
tar xzf vigie_0.1.0_linux_amd64.tar.gz
install -m755 vigie ~/.local/bin/

# 2 · point the client at YOUR OWN vigied server
vigie init \
  -server https://vigie.example.com \
  -token  $VIGIE_TOKEN

# 3 · stream this machine's sessions
vigie watch

# 4 · watch, from anywhere
vigie tui            # terminal
open https://vigie.example.com # web
